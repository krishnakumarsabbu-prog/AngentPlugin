# Repo Assurance

Apply a focused, complete engineering workflow. Choose the relevant reference for the task:

- **Implementing, debugging, or refactoring:** follow [repo-assurance-edit](./references/repo-assurance-edit.md).
- **Reviewing a change:** follow [repo-assurance-review](./references/repo-assurance-review.md).

Use `full` by default. Switch level when the user asks: `/repo-assurance lite|full|ultra|off`.
